# Sales & Gross Income Analytics Dashboard

## Overview
An interactive Power BI dashboard designed to track organizational sales distribution and evaluate gross income performance across major operating branch cities (Bangalore, Chennai, Ahmedabad).

## Key Analytical Insights
* **Branch Sales Share:** Evaluates the percentage contribution (%GT Sum of Total) across each active branch location.
* **Regional Income Distribution:** Analyzes gross income contribution by city to highlight high-performing market locations.

## Tools & Technologies
* **Data Visualization:** Power BI Desktop (Pie & Donut Charts, Regional Segmentation)
* **Data Transformation:** Power Query ETL Workflows
* **Reporting:** Visual report structuring & PDF exporting
